# Elite Item Listing System

Product lookup, pricing, labels, training, messages and Recovery Studio.

## Recovery Studio

Sign in and open `/#recovery`, or choose Recovery in the navigation. Pair a computer using the downloadable Python companion or the paired-companion USB release. See [setup, deployment and verification](docs/recovery-studio.md). This feature reports hardware and prepares a recovery toolkit; it does not automatically erase disks or install operating systems.
